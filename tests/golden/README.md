# 정답 예시(golden)

출처: HealthCheckSchema `work/testcases/case_shapes/` 중 turn-engine 네 컴포넌트에 해당하는 입출력 예시(헤드 추출, 2026-10-15).

- 요구사항 케이스마다 턴별로 `(입력, 출력)` 쌍이 있다. 입력을 해당 함수에 넣었을 때 출력이 같은지 비교한다.
- **실행 결과가 아니라 요구 작성자가 만든 정적 예시**이고 `correctness_claim: false`다. 같지 않다고 바로 구현이 틀렸다는 뜻은 아니다. 차이는 (a) 구현 결함, (b) 규칙 문서의 해석 차이, (c) 예시 자체의 오류 중 하나다. 어느 것인지 판단해 (a)는 고치고 (b)는 규칙 해석 목록에 반영하고 (c)는 변경 요청으로 헤드에게 알린다.
- 짝이 되는 입력/출력은 같은 `turn`의 같은 컴포넌트 계약이다. 한 케이스에 같은 계약이 여러 턴 있다.
